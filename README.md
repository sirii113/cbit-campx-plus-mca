## 📐 R-25 Syllabus Continuous Internal Evaluation (CIE) Scheme

$$\text{R25 Total CIE (45 Marks)} = \text{Average of 2 Mids (20M)} + \text{3 Slip Tests (15M)} + \text{Average of 2 Assignments (10M)}$$

1. **Mid-Term Examinations (2 Mids x 20 Marks Each)**:
   - Evaluated out of 20 marks each.
   - **Mid Component = Average of Mid 1 and Mid 2** (Max 20 Marks).
2. **Slip Tests (3 Tests x 5 Marks Each)**:
   - Slip Test 1 (5M) + Slip Test 2 (5M) + Slip Test 3 (5M).
   - **Slip Test Component = Total of 3 tests** (Max 15 Marks).
3. **Assignments (2 Assignments x 10 Marks Each)**:
   - Assignment 1 (10M) & Assignment 2 (10M).
   - **Assignment Component = Average of Assignment 1 and Assignment 2** (Max 10 Marks).
4. **Final Scaled Continuous Internal Evaluation (CIE)**:
   - $\text{Total CIE} = 20 + 15 + 10 = \mathbf{45\text{ Marks}}$.
   - Minimum pass threshold is $\ge 18\text{ Marks}$ (40%).
